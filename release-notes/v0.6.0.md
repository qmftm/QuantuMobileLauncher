### 수정
- **게임을 시작하면 바로 꺼지던 문제를 고쳤습니다.** 실행 인자의 `${...}` 자리표시자를 바꾸는 정규식이 안드로이드의 정규식 엔진에서 오류를 내서, 준비 단계가 끝나자마자 앱이 종료되고 있었습니다. 이제 정규식을 쓰지 않고 처리합니다.
- 준비 작업 중 예기치 않은 오류가 나도 앱이 꺼지지 않고, 실패 메시지로 알려줍니다.

### 알아 두세요
- 이 버전부터 게임 실행이 Java 시작·화면 연결 단계까지 처음으로 진행됩니다. 이 단계들은 아직 실기기에서 검증되지 않았으니, 꺼지거나 안 뜨면 홈 → 게임 로그(또는 꺼진 뒤 열리는 로그 화면)의 내용을 공유해 주세요.

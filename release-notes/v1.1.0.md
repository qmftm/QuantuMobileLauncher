## 추가
- **잠수 봇 (새 "잠수" 탭)**: 게임을 켜지 않고 마인크래프트 자바 서버에 접속만 해 둡니다. PC 없이 폰만으로 동작합니다.
  - 서버를 여러 개 등록(이름·주소·포트·계정)하고 서버마다 따로 켜고 끕니다. 켜 둔 상태는 앱이나 폰을 다시 켜도 유지됩니다.
  - 봇은 20~45초마다 0.6초 웅크리기만 합니다. 이동·점프·시점 회전은 하지 않습니다.
  - 끊기거나 추방되면 10초 → 20초 → 40초 → 60초 간격으로 다시 접속합니다.
  - 죽으면 자동으로 리스폰합니다.
  - 서버별 상태(꺼짐 / 접속 중 / 접속됨 / 재접속 대기 / 오류)와 마지막 사유(킥 메시지 등)를 화면과 알림에 보여 줍니다. 알림에서 모두 중지할 수 있습니다.
  - 폰을 재부팅하면 켜져 있던 서버에 다시 접속합니다. 설정 → 잠수 봇에서 끌 수 있습니다.
  - 지원 서버: **1.20.2 ~ 26.3** 정식 버전. 계정은 계정 탭의 마이크로소프트/오프라인 계정을 그대로 씁니다.
- 1.0.0(배포 전)의 변경을 모두 포함합니다: 모드·리소스 팩·셰이더를 **다운로드 탭** 하나로 통합.

## 변경
- 하단 탭: 플레이 · 인스턴스 · 다운로드 · **잠수** · 설정

## 알아 두세요
- 실제 26.3 서버에서 잠수 추방 시간을 1분으로 두고 150초간 확인했습니다(추방 없음, 자동 리스폰, 킥 사유 표시). 폰에서의 장시간 동작은 아직 확인 전입니다.
- 화면이 꺼져도 접속을 유지하려면 설정 → 잠수 봇 → **배터리 최적화 제외**를 허용해 주세요.
- 26.3 서버는 기본으로 화이트리스트가 켜져 있습니다. 봇 계정을 화이트리스트에 넣어야 접속됩니다.

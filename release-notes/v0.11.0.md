## 수정
- 서버 주소의 SRV 레코드가 동작하지 않아, 포트를 숨겨 둔 서버(예: `iconic5.mcv.kr`는 실제 포트가 88번)에 포트를 직접 적지 않으면 접속되지 않던 문제를 고쳤습니다. 안드로이드에는 JVM이 DNS 서버를 찾는 설정 파일이 없어 게임의 SRV 조회가 항상 실패했습니다. 이제 런처가 기기의 DNS 서버(없으면 1.1.1.1, 8.8.8.8)로 직접 조회합니다. 마인크래프트 26.x에 적용됩니다.

## 추가
- Q, F, 핫바 ◀▶ 버튼을 처음 한 번 누른 뒤에도 꾹 누르고 있으면 계속 반복해서 눌립니다(키보드 자동 반복처럼). Q를 꾹 누르면 아이템을 계속 버립니다. 컨트롤 편집에서 버튼마다 "꾹 누르면 반복"을 켜고 끌 수 있습니다.

## 알아 두세요
- 접속할 때 게임 로그에 `[qm-srv] 서버주소 -> 호스트:포트` 줄이 남습니다. 포트를 직접 적은 주소는 그대로 그 포트로 접속합니다.

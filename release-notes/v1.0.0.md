## 변경
- **다운로드 탭 통합**: 모드와 비주얼(리소스 팩·셰이더)로 나뉘어 있던 두 화면을 다운로드 탭 하나로 합쳤습니다.
  - 위에서 종류(모드 / 리소스 팩 / 셰이더)를 고르고, 아래에서 둘러보기(Modrinth)와 설치됨을 전환합니다.
  - 모드: 설치된 모드 켜기·끄기·삭제, 업데이트 확인, 필요한 모드(의존성) 자동 설치.
  - 리소스 팩·셰이더: 기기에서 파일 추가, 리소스 팩 켜기·순서 바꾸기, 사용할 셰이더 선택, 삭제.
  - 같은 기능이 두 화면에 따로 있던 부분(검색, 다운로드, 설치 확인)을 하나로 정리했습니다.
- 0.10.0~0.11.2의 변경을 모두 포함합니다: 버튼 배치·크기 정리, 꾹 누르면 반복(Q·F·핫바), 서버 주소 SRV 조회(`iconic5.mcv.kr`처럼 포트를 숨긴 서버), 키보드 포커스 복구, Key 버튼 글자 입력, 뒤로가기 = Esc.

## 알아 두세요
- 설치한 모드·팩·셰이더와 설정은 그대로 유지됩니다.
- "Services are unavailable"로 온라인 서버에 못 들어가는 문제는 아직 원인을 조사 중입니다. 서버 접속이 안 될 때 게임 로그의 `[qm-net]` 줄을 보내 주세요.

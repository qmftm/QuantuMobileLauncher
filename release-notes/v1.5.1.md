## 추가
- **PC 프로그램 자동 실행**: PC 프로그램에 트레이 아이콘(작업 표시줄 오른쪽 아래)이 생겼습니다. 메뉴에서 연결 코드 보기, 로그 보기, 종료를 할 수 있고, **"컴퓨터 켤 때 자동 실행"**을 체크하면 다음 로그인부터 **cmd 창 없이** 백그라운드로 켜집니다.
  - 윈도우 zip에 창 없는 실행 파일 `QuantuMobile-AFK-Background.exe`가 추가됐어요. 출력은 설정 폴더의 `host.log`에 남습니다.
  - 맥·리눅스(jar)는 `--autostart on|off` 옵션도 쓸 수 있습니다. PC 프로그램은 한 PC에서 하나만 실행됩니다.
- **AFK 재접속 대기 시간**: 10초 → 20초 → 40초 → 1분 → **3분 → 5분**(최대). 서버가 오래 꺼져 있어도 5분마다만 시도합니다. 앱에는 "재접속 대기 (4분 30초)"처럼 표시됩니다.

## 수정
- 와이파이가 잠깐 끊겨도 앱 목록에서 **PC와 PC 서버가 사라지지 않습니다**. 마지막 상태를 보여 주다가 4번 연속 실패하면 오프라인으로 바꿉니다.
- AFK **서버 추가/수정 창을 열면 키보드가 저절로 뜨던** 문제 (계정·실행 위치·아이콘 선택을 가렸습니다).
- 게임 안 **키보드를 껐다 켜면 입력이 안 먹던** 문제.
- **최근 앱에서 게임을 밀어 닫으면** 백그라운드에서 게임도 같이 종료됩니다. (홈 버튼으로 나가면 지금처럼 계속 실행)

## 알아 두세요
- PC 프로그램도 이번 버전으로 바꿔야 자동 실행과 트레이 아이콘을 쓸 수 있습니다.
- 윈도우 트레이/레지스트리 등록은 실제 윈도우 PC에서는 아직 확인하지 못했습니다.

### 수정
- **Java 런타임을 불러오지 못해 게임이 시작되지 않던 문제를 고쳤습니다.** 받은 Java 런타임의 모든 라이브러리가 `libc++_shared.so` 를 필요로 하는데 앱에 들어 있지 않아서, 어떤 라이브러리도 로드되지 않고 "종료 코드 -1"로 끝나고 있었습니다. 이제 앱에 포함하고 가장 먼저 불러옵니다.
- OpenAL 라이브러리를 엉뚱한 폴더에서 찾던 것을 LWJGL 폴더에서 찾도록 고쳤습니다.
- 로그에 `dlopen ... failed: (null)` 로 찍히던 오류 메시지가 실제 원인으로 나오도록 고쳤습니다.

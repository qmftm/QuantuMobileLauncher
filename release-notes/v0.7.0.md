### 추가
- **마인크래프트 26.x(26.3 등) 실행 시도.** 26.x 는 창 시스템이 GLFW 에서 SDL3(LWJGL 3.4.3)로 바뀌어서, 이를 위한 별도 경로를 만들었습니다.
  - 안드로이드용 **SDL3**(3.4.16, 이 런처 전용 패치 포함)와 **LWJGL 3.4.3** 네이티브(arm64)를 직접 빌드해 앱에 넣었습니다. 빌드 스크립트는 `third_party/natives/` 에 있습니다.
  - OpenGL 은 **MobileGlues**(LGPL-2.1)를 SDL 의 EGL 라이브러리로 연결해 데스크톱 GL → 폰의 GLES 로 변환합니다.
  - 26.x 는 모장의 LWJGL 3.4.3 jar 를 그대로 쓰고, 그래픽 백엔드는 OpenGL 로 고정합니다(`--graphicsBackend opengl`).
  - 1.21.x 이하는 기존 방식(LWJGL 3.3.3 + GLFW) 그대로입니다.

### 변경
- 지난 버전에서 넣으려던 "26.x 는 지원하지 않는다" 안내 대신 위 경로로 실행합니다. (이전 0.6.5 는 배포되지 않았고 이 버전에 합쳐졌습니다.)

### 알아 두세요
- **26.x 는 아직 실험 단계입니다.** 개발 환경에는 실제 기기가 없어서 실행을 확인하지 못했습니다. 안 뜨면 홈 → 게임 로그를 공유해 주세요.
- 26.x 에서는 터치 조작이 SDL 기본(터치 = 마우스)만 됩니다. 가상 버튼 조작판은 아직 연결되지 않았습니다.
- 26.x 는 arm64-v8a 기기에서만 실행됩니다. Vulkan 백엔드와 Sodium·Iris 는 아직 지원하지 않습니다.

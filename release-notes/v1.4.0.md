## 추가
- **다른 와이파이·LTE에서도 PC 연결**: 폰이 PC와 다른 네트워크에 있어도 AFK PC에 연결됩니다.
  - PC 프로그램이 Cloudflare 퀵 터널을 자동으로 열고(계정·포트 개방 필요 없음), 지금 주소를 암호화해서 공유합니다.
  - 앱에는 **연결 코드만** 입력하면 됩니다. 같은 와이파이면 직접, 밖에서는 터널로 알아서 연결하고, PC를 다시 켜서 주소가 바뀌어도 다시 입력할 필요가 없습니다.

## 수정
- v1.3.0에서 같은 와이파이의 PC에 연결되지 않던 문제 (안드로이드가 암호화되지 않은 http 연결을 막음). 주고받는 내용은 원래 연결 코드로 암호화돼 있습니다.

## 알아 두세요
- **PC 프로그램도 이번 버전의 `QuantuMobileLauncher-AFK-Host.jar` 로 바꿔 주세요.** 처음 실행할 때 외부 접속용 `cloudflared` 를 한 번 자동으로 받습니다.
- 주소 공유에는 공개 알림 서버 ntfy.sh, 외부 접속에는 Cloudflare를 씁니다. 둘 다 무료이고 가입이 필요 없으며, 내용은 연결 코드로 암호화돼 있어 읽을 수 없습니다.
- 외부 접속을 원하지 않으면 PC에서 `--lan-only` 로 실행하세요(같은 와이파이 전용).
